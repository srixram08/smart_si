Solving the Blind Monthly Bill Shock

Electricity bills are historically retrospective. Our IoT architecture turns passive consumption into active, predictive cost control.

The Blind Utility Bill

Traditional utility meters lock data away. Homeowners only see the damage 30 days later, unable to pinpoint which faulty air conditioner, geyser, or appliance drove up the tariff slab.

Continuous High-Speed ADC

The ESP32 samples ZMPT101B and ACS712 sensors with a 20-sample oversampling filter every 2 seconds, computing instantaneous active power (P = V × I) and accumulating true kilowatt-hours.

Deterministic Cost Projections

Instantaneous tariff calculations convert kilowatt-hours to Rupees (₹) immediately. The built-in forecasting engine projects today's total and monthly run rates to prevent budget blowouts before they happen.

Measures AC mains voltage up to 300V RMS using an onboard high-precision micro-transformer and LM358 op-amp. Wired to ESP32 ADC1 (GPIO 35).

Formula 01

Active Real Power (Watts)

P = V_rms × I_rms × cos(θ)
Calculated deterministically on the ESP32 microcontroller through continuous synchronous sampling of voltage and current analog channels.

Formula 02

Accumulated Energy (kWh)

E += (P × Δt) / 3,600,000
Riemann sum integration every 2-second publishing window. Preserves energy state across sessions.

Formula 03

Deterministic Billing Engine

Cost = E(kWh) × Tariff Rate (₹/kWh)
Transparent computation with zero hidden fees. Updates live whenever the tariff slider changes.

ESP32 Firmware (sketch.ino):

#include <WiFi.h> #include <PubSubClient.h> const char* WIFI_SSID = "Wokwi-GUEST"; const char* MQTT_SERVER = "broker.hivemq.com"; const int MQTT_PORT = 1883; const char* TOPIC = "mikey/energy/data"; const int PIN_CURRENT = 34; // ACS712 Stand-in const int PIN_VOLTAGE = 35; // ZMPT101B Stand-in const float ACS_SENS = 0.185; // 185 mV/A sensitivity const float MAX_AMPS = 5.0; const float MAX_VOLTS = 300.0; const float TARIFF = 8.0; // Default Rs/kWh WiFiClient wifi; PubSubClient mqtt(wifi); float kwh = 0; unsigned long lastPublish = 0, lastCalc = 0; void setup() { Serial.begin(115200); WiFi.begin(WIFI_SSID, "", 6); while (WiFi.status() != WL_CONNECTED) delay(300); mqtt.setServer(MQTT_SERVER, MQTT_PORT); lastCalc = millis(); } void loop() { if (!mqtt.connected()) { String id = "esp32-energy-" + String(random(0xffff), HEX); mqtt.connect(id.c_str()); } mqtt.loop(); float vAdc = analogRead(PIN_CURRENT) * 3.3 / 4095.0; float amps = fabs((vAdc - 1.65) / (ACS_SENS * (3.3 / 5.0))); if (amps > MAX_AMPS) amps = MAX_AMPS; if (amps < 0.05) amps = 0; float volts = analogRead(PIN_VOLTAGE) * MAX_VOLTS / 4095.0; float watts = volts * amps; unsigned long now = millis(); kwh += watts * (now - lastCalc) / 3.6e9; lastCalc = now; if (now - lastPublish >= 2000) { lastPublish = now; char msg[200]; snprintf(msg, sizeof(msg), "{\"v\":%.1f,\"i\":%.2f,\"p\":%.1f,\"kwh\":%.5f,\"cost\":%.3f}", volts, amps, watts, kwh, kwh * TARIFF); mqtt.publish(TOPIC, msg); } }
